# Tarea-05
Aquí se realizara el repositorio para la tarea 5

Reflexión sobre lo que aprendí durante este ejercicio
Durante este ejercicio aprendí a crear un programa simple pero funcional en Python. Comencé con un sistema de detección de edades básico y luego lo mejoré añadiendo un bucle while para hacerlo más interactivo. Esto me permitió practicar conceptos fundamentales como:

Uso de condicionales (if, elif, else)
Implementación de bucles (while)
Manejo básico de errores con try-except
Interacción con el usuario mediante input y print
Convertir tipos de datos (de string a int)

Me di cuenta de que incluso un programa sencillo puede ser útil y funcional. Además, comprendí la importancia de pensar en la experiencia del usuario, por ejemplo, al darle la opción de revisar múltiples edades sin tener que reiniciar el programa.
¿Cómo me siento al usar Git y GitHub?
Al usar Git y GitHub me siento más organizado y seguro con mi código. Al principio era un poco intimidante con todos los comandos y conceptos como repositorios, commits, push y pull, pero ahora aprecio mucho el control que me da sobre mis proyectos.
Me gusta especialmente la capacidad de guardar diferentes versiones de mi código, lo que me permite experimentar sin miedo a arruinar lo que ya funciona. También valoro poder colaborar con otros desarrolladores y tener mi trabajo respaldado en la nube.
GitHub ha sido una plataforma excelente para mostrar mis proyectos y seguir el trabajo de otros desarrolladores, lo que me ha ayudado a aprender y mejorar mis habilidades. En general, me siento mucho más profesional y productivo utilizando estas herramientas.
